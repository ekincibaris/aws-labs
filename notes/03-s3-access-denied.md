When we ran the viewer Lambda function to view a report, we got an AccessDenied error naming the missing kms:Decrypt action. Then we examined the object with aws s3api head-object and saw that it was encrypted with SSE-KMS. So the IAM role needed permission to decrypt. We added the kms:Decrypt action to the role’s policy, which fixed the issue. To prevent this, the IAM role should be granted both encrypt and decrypt permissions and the read path should be tested after every apply. We should also run terraform plan before terraform apply and read it carefully.
