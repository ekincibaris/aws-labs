When we curled the shop URL, we got a 502 Bad Gateway error from the ALB, and aws elbv2 describe-target-health showed both targets failing health checks on port 80. Then we inspected the instance with ss -tlnp and saw that the app was actually listening on port 8080 while nothing was listening on port 80. So the target group was routing traffic and health checks to the wrong port. We updated the target group port in alb.tf from 80 to 8080, which fixed the issue. To prevent this, the application port should be defined once in a shared variable and the public URL should be smoke-tested after every deploy. We should also run terraform plan before terraform apply and read it carefully.
